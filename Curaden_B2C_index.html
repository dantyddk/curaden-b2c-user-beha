Metric definitions & calculation logic

Filters select users by their first-order date. The behavior below is cumulative at the snapshot date. Churn user = more than 365 days since the last order, regardless of order count. New user = one lifetime order and no more than 365 days since last order. Repeat user = two or more lifetime orders and no more than 365 days since last order. These three groups are mutually exclusive. GMV and discount are lifetime source fields in EUR. Discount is not total acquisition cost. Promo sensitivity uses the source field, whose business definition needs verification.

Days to 2nd, 3rd and 4th are measured from the first order among users who reached each milestone. Average gap is the average of user-level gaps. Churn days means days since last order; min and max use the same definition. Drop rate from order N to N+1 = (users with at least N orders − users with at least N+1 orders) / users with at least N orders, based on the current snapshot; this is not a fixed-time retention rate. Recent cohorts have had less time to repeat.
